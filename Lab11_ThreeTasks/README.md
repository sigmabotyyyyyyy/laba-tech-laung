# Лабораторная работа №11 — React: Props и State

## О проекте

В проекте объединены три практических задания лабораторной работы. Приложение оформлено как единая интерактивная панель и содержит три раздела-переключателя.

### 1. Счётчик лайков — `LikeButton`
- Один большой интерактивный палец вверх вместо нескольких карточек людей.
- Подпись компонента передаётся через `props`.
- Количество лайков хранится в локальном `state` через `useState`.
- При нажатии счётчик увеличивается, палец получает анимацию, появляется эффект `+1 LIKE`.
- Есть сброс счётчика и сохранение значения в `localStorage`.

### 2. Каталог языков программирования — `CourseCard`
- Карточки JavaScript, Python, C++, Java, C# и Go.
- `CourseCard` получает данные выбранного языка через `props`.
- Родительский компонент `App` хранит выбранный язык в `state`.
- После нажатия открывается подробный профиль: описание, назначение, особенности, факты и пример кода.
- Блок с информацией появляется с анимацией.

### 3. Электронный журнал — `StudentRow`
- Можно добавлять студентов с ФИО, группой, специальностью, возрастом и курсом обучения.
- Для каждого студента можно выставлять оценки от 1 до 5 и удалять запись из журнала.
- Есть поиск по имени, группе и специальности.
- `StudentRow` получает объект студента через `props`.
- Родительский `App` хранит список студентов и оценки в `state`.
- Средний балл каждого студента, общий средний балл, число оценок и число групп пересчитываются автоматически.
- Список и оценки сохраняются в `localStorage`.

## Как запустить

1. Скачайте и распакуйте архив в отдельную папку.
2. На компьютере с Windows дважды нажмите `start.bat`.
3. Батник запустит встроенный локальный сервер PowerShell и откроет `http://localhost:8000`.
4. Чтобы остановить сервер, закройте отдельное окно PowerShell.

Не требуются Node.js, npm, Python или установка дополнительных библиотек. Для загрузки React 18 и Babel с CDN во время запуска требуется подключение к интернету.

## Где используются Props и State

| Компонент | Props | State |
|---|---|---|
| `LikeButton` | `caption` — подпись | `likes` — количество лайков |
| `CourseCard` | `course`, `selected`, `onSelect` | Выбранный язык хранится в родительском `App` |
| `StudentRow` | `student`, `onAddGrade`, `onRemove` | Список студентов и оценки хранятся в родительском `App`; локально строка хранит выбранную оценку |

## Проверка работы (тест-кейсы)

| № | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Нажать на большой палец | Счётчик увеличивается на 1, проигрывается анимация |
| 2 | Нажать «Сбросить счётчик» | Количество лайков становится равным 0 |
| 3 | Выбрать Python в каталоге | Справа появляется описание Python, особенности и пример кода |
| 4 | Выбрать другой язык | Информация меняется, блок повторно анимируется |
| 5 | Добавить студента с заполненными данными | Новая запись появляется в списке, счётчик студентов увеличивается |
| 6 | Добавить оценку студенту | Оценка появляется в карточке, средний балл и статистика обновляются |
| 7 | Ввести часть имени в поиск | Отображаются только подходящие записи |
| 8 | Удалить студента | Запись исчезает, статистика пересчитывается |
| 9 | Перезагрузить страницу | Лайки, список студентов и оценки сохраняются в браузере |
| 10 | Попробовать добавить студента без обязательных полей или с недопустимым возрастом | Форма показывает сообщение и не создаёт запись |

## Что показать при защите

1. В разделе лайков объяснить, что `caption` — это `props`, а число лайков — `state`.
2. В каталоге выбрать несколько языков и показать, что дочерние карточки получают данные через `props`, а родитель хранит `selectedCourse`.
3. В журнале добавить нового студента, затем поставить ему несколько оценок. Показать автоматический пересчёт среднего балла и статистики.
4. Обратить внимание, что состояние обновляется через функции-сеттеры React, а не прямым изменением объектов и массивов.

## Важное замечание

Весь исходный код приложения находится в одном файле `index.html`. Внешние ресурсы — только React 18, ReactDOM и Babel CDN. Данные `localStorage` хранятся локально в браузере и не отправляются на сервер.
