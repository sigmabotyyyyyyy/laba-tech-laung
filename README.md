# laba tech laung

8 лабораторных по дисциплине «Языки и технология программирования». В каждой — **три самостоятельных проекта**: низкий (`low`), средний (`medium`) и высокий (`high`) уровень. Всего **24 проекта**.

Номера вариантов не были заданы, поэтому выбран один вариант каждого уровня из соответствующей методички. `low` соответствует базовому уровню, `high` — повышенному.

## Структура

```text
lab-01/ … lab-08/
  low/      # низкий уровень
  medium/   # средний уровень
  high/     # высокий уровень
```

Внутри каждого проекта: исходники, `README.md`, `REPORT.md` и PNG-снимки результатов.
В Python-проектах также есть фактический протокол запуска `sample-output.txt`.
ФИО и группа в отчётах не выдуманы: перед сдачей заполните эти два поля.

## Быстрый запуск

Нужен Python 3.10 или новее. Зависимости pip и npm для самих проектов не требуются.

Python, пример из корня репозитория:

```sh
python3 lab-01/low/main.py
python3 lab-03/high/main.py
```

Веб-проекты (лабы 4–8), из корня:

```sh
python3 -m http.server 8000
```

Откройте [каталог проектов](http://localhost:8000/) или, например,
[мастер заявки](http://localhost:8000/lab-08/high/). Остановка сервера: Ctrl+C.
На Windows можно использовать `py` вместо `python3`.

HTML, CSS и JavaScript разделены. Фреймворки и внешние CDN не используются.
Для `fetch()` и Web Storage используйте HTTP-сервер, а не `file://`.
Проекты автономны: можно скопировать любую папку уровня и запускать отдельно.

## Проверки

```sh
python3 -m unittest discover -s tests -v
node tests/test_storage.cjs
```

Первая команда запускает 13 тестовых методов, включая 18 числовых примеров,
проверку ограничений линейных алгоритмов и сценарии ООП.
Вторая — 21 проверку JSON/Storage без браузера (Node.js нужен только для этих тестов).
Фактические результаты: `tests/python-results.json`, `tests/storage-results.json`
и `tests/browser-results.json`. Подробные действия и ожидания — в отчёте каждого проекта.

Ограничения первых двух лабораторных соблюдены: без if, циклов, коллекций и пользовательских функций.
В них входные данные должны соответствовать предусловиям в комментариях.
Веб-лабы 4–7 хранят данные в памяти страницы. В лабораторной 8 используются отдельные
ключи Storage; очистка всего origin через `clear()` не выполняется.
Все имена, адреса e-mail и PIN в примерах вымышлены.

Проверено в браузере: **79 сценариев**, все пройдены.
